# ThynkTask LLC website

Static website for ThynkTask LLC, real estate transaction coordination in Hampton Roads, Virginia. Hosted with GitHub Pages.

## Pages
- `index.html`: homepage
- `services.html`: services
- `about.html`: about Tahiri Asencio
- `contact.html`: contact form (delivered by FormSubmit to the business inbox)
- `transaction-coordinator-newport-news-va.html`: local SEO page for Newport News
- `thank-you.html`, `404.html`

## Editing
Styles live in `assets/styles.css`. To add the headshot, save it as `assets/tahiri-asencio.jpg` and uncomment the `<img>` line inside each `.portrait` block.
